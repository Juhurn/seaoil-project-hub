Route deviation audit

Compares each truck's first-to-last recorded GPS positions against a Google driving route. This is a preliminary screening check; confirm the actual dispatch route before concluding a deviation.

Upload and analyze a GPS file first. Route lookup will use each vehicle's earliest and latest valid GPS coordinates.

What the checks mean

Long stop: consecutive records for the same truck with unchanged coordinates for at least the configured threshold. Speed alert: recorded speed above your selected limit. GPS gap: time between consecutive records for the same truck exceeds the threshold. These are screening flags, not proof of misconduct. Route deviation requires a planned route or approved geofence dataset, which this version does not infer.
